# WhatsApp Web Çevirici

## Açıklama

WhatsApp Web Çevirici, WhatsApp Web arayüzünde mesajlarınızı anında çevirmenizi sağlayan kullanışlı bir tarayıcı eklentisidir. Her mesajın yanında bir çeviri butonu ve dil seçim alanı bulunur, böylece mesajları kolayca çevirebilirsiniz.

## Özellikler

- **Anında Çeviri**: Her mesajın yanında bulunan "Çevir" butonu ile tek tıklamayla çeviri yapabilirsiniz
- **Çoklu Dil Desteği**: 30'dan fazla dil desteği ile istediğiniz hedef dile çeviri yapabilirsiniz
- **Ücretsiz ve Hızlı**: Lingva Translate API kullanarak herhangi bir API anahtarı gerektirmeden ücretsiz çeviri sağlar
- **Kolay Kullanım**: Herhangi bir ek menüye gitmeye gerek kalmadan, direkt mesaj alanında çeviri yapabilirsiniz
- **Özelleştirilebilir**: Her mesaj için farklı hedef dil seçebilirsiniz

## Yükleme

Eklenti şu anda Chrome Web Mağazası'nda yayında olmadığı için geliştirici modunda yüklemeniz gerekiyor:

1. Bu GitHub deposunu indirin veya klonlayın
2. Google Chrome tarayıcınızı açın
3. Adres çubuğuna `chrome://extensions` yazarak uzantılar sayfasına gidin
4. Sağ üst köşedeki "Geliştirici modu" seçeneğini etkinleştirin
5. "Paketlenmemiş öğe yükle" butonuna tıklayın
6. İndirdiğiniz klasörü seçin ve "Klasör Seç" butonuna tıklayın
7. Eklenti başarıyla yüklenecek ve Chrome'un sağ üst köşesindeki uzantılar alanında görünecektir

## Nasıl Kullanılır?

1. Eklentiyi yükledikten sonra WhatsApp Web'e gidin (https://web.whatsapp.com/)
2. Mesajların yanında otomatik olarak "Çevir" butonu görünecektir
3. Çevirmek istediğiniz mesajın yanındaki butona tıklayın
4. Dilediğiniz hedef dili seçebilirsiniz (varsayılan olarak İngilizce'dir)
5. Çeviri, mesajın altında görünecektir

## Teknik Bilgiler

Bu eklenti tamamen JavaScript ile geliştirilmiştir ve Chrome Manifest V3 standardını kullanmaktadır. Çeviri için Lingva Translate API kullanılarak Google Translate kalitesinde ücretsiz çeviri hizmeti sunulmaktadır.

## Güvenlik

Eklenti hiçbir mesaj verisini saklamamakta veya üçüncü taraflarla paylaşmamaktadır. Tüm çeviriler doğrudan API üzerinden gerçekleştirilir ve hiçbir veri kaydedilmez.
